# Public landing design reference

Source: user-supplied Vite design-system extraction, captured 2026-05-04 via [Inspo](https://inspomcp.dev/screens/vite-dev), referencing [vite.dev](https://vite.dev). Adapted for StressForge on 2026-10-28. This records design inspiration, not copied Vite assets or endorsements.

## Reference principles

- Dark technical specimen composition with clear geometric hierarchy.
- Midnight #0c0912 and slate #14121a surfaces; violet #b39aff accents, restrained fine borders.
- Strong heading/body contrast, generous 32/64/112px spacing, small 4/6/8px radii.
- Meaningful motion and readable content; no decorative particle fields, fake customer logos or unsupported product claims.

## StressForge interpretation

Use existing Archivo, Instrument Sans and JetBrains Mono fonts instead of adding unlicensed reference typefaces. Keep landing colors scoped to .sf-landing, retaining the authenticated application's light/dark/cobalt tokens.

A connected four-layer architecture is the specimen. Hero: assembled system and immediate product explanation. Problem: diagrams conceal capacity limits. Sticky anatomy: assemble, examine, rethink; scroll opens layers then reassembles them. Ending: model limitations and actual register/login entry. The SVG is an illustration, never a fabricated simulation result.

Animation is a clamped, reversible position mapping using one requestAnimationFrame update per scroll frame. Movement uses transforms and label opacity; there is no scroll hijacking, timer-driven sequence or new animation dependency. Reduced motion uses a static exploded specimen and shorter nonsticky narrative. All copy and links render on the server without JavaScript.

Four proposed account roles remain future project scope. The landing does not advertise unimplemented review, instruction, administration or real-AI functionality.
